# 鼓動 KODO

Apple Watch の健康データ（アクティビティ・心拍・睡眠・からだ）をグラフで見るアプリ。
https://sho3690.github.io/kodo/

## しくみ

- iPhone の「ヘルスケア」アプリが書き出す `export.zip` を、ブラウザの中で読み込む。
- 読み込んだ数値は、その端末のブラウザ内（IndexedDB）にだけ保存する。**どこにも送信しない**（ページの設定で外部通信を禁止している）。
- このリポジトリにあるのはアプリの部品だけ。健康データは置かない（`.gitignore` で zip / xml を除外）。

## データの入れ方

1. iPhone で「ヘルスケア」を開き、右上の自分のアイコンをタップ
2. 「すべてのヘルスケアデータを書き出す」をタップ（数分かかる）
3. 「“ファイル”に保存」を選ぶ
4. KODO を開き、「Choose export file」でその `export.zip` を選ぶ

書き出しには毎回すべての履歴が入っているので、新しく読み込むと中身は置き換わる。

## 開発

- `npm test` — 読み込み部分のテスト
- 画面の確認は `python3 -m http.server 8797 --bind 127.0.0.1` で開く
- グラフは ECharts 6.1.0（`vendor/`）を evilcharts の作法で描画
